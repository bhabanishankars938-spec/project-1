Frequently Asked Questions

Everything you need to know about the HireNexa recruitment ecosystem, AI screening intelligence, and account governance.

What is HireNexa 2.0 and who is it built for?

HireNexa 2.0 is an enterprise-grade AI-powered recruitment, talent intelligence, and career development ecosystem. It serves 4 key personas:
1. Candidates: Job discovery, explainable ATS resume diagnostics, candidate project portfolio with Supabase file storage, and entrance exam preparation (NIMCET, OJEE, CUET-PG).
2. Employers & Recruiters: Multi-tenant job posting, India location hierarchy filtering, applicant tracking system (ATS) with 5 pipeline stages, and structured interview scheduling.
3. Freelancers: High-value technical gig marketplace and milestone delivery.
4. Platform Owner: Comprehensive governance suite, company approval/rejection workflows, subscription plans, and audit logs.

How does the HireNexa AI Assistant work without external API keys?

HireNexa features a dual-engine architecture. When external cloud LLM keys (such as Google Gemini) are available, it uses them. When offline or without external keys, HireNexa activates its built-in LocalPlatformIntelligenceProvider and TechnicalKnowledgeEngine. This engine executes real database queries via Supabase tools (e.g. searching jobs, candidates, and exam syllabus) and provides thorough, verified technical explanations and code walkthroughs right inside the platform—without redirecting users to ChatGPT or external websites.

Does HireNexa support locations across all of India?

Yes. The platform includes a dedicated database hierarchy covering all 36 Indian States and Union Territories, 71+ districts, 73+ cities, and 212+ localities and PIN codes. Users can search and filter opportunities nationally or locally (including Bhubaneswar, Bengaluru, Hyderabad, Mumbai, Delhi-NCR, Pune, etc.) as well as Pan-India Remote.

How are candidate project files stored and previewed?

Candidate project attachments are stored securely in Supabase Cloud Storage (`candidate-projects` bucket). All file downloads and previews use time-limited signed URLs (valid for 1 hour) with virus/mime-type validation, preventing unauthorized direct bucket scraping.

Is HireNexa free to use for jobseekers?

Yes, job discovery, profile creation, portfolio uploads, ATS resume diagnostics, and entrance prep question banks are 100% free for candidates. Monetization is handled through employer enterprise subscription plans and recruitment tier allocations managed by the Platform Owner.
