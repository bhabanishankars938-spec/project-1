High-Frequency Interview Questions

1. How does Django handle database concurrency and atomic transactions?

Django provides `transaction.atomic()` context manager and decorator to wrap queries in an ACID database transaction. Under the hood, it creates a savepoint (`SAVEPOINT` in PostgreSQL). If an unhandled exception occurs inside the atomic block, Django rolls back all changes to ensure data consistency. For concurrency, `select_for_update()` can be used to acquire row-level locks preventing race conditions during balance or inventory updates.

2. What is the fundamental difference between `select_related` and `prefetch_related`?

`select_related` performs an SQL `INNER JOIN` (or `LEFT OUTER JOIN`) in the same single database query. It works for single-valued relationships: ForeignKey (`1-to-N` from the child side) and OneToOneField.
`prefetch_related` performs a separate lookup query and joins the results in Python memory. It is required for multi-valued relationships: ManyToManyField and reverse ForeignKeys (`1-to-N` from parent side).

3. How does React 18 Concurrent Rendering improve perceived performance?

React 18 introduces interruptible rendering. Instead of blocking the main JavaScript thread until an entire component tree re-renders, React splits rendering into small chunks. High-priority updates (typing, clicking) can interrupt low-priority transitions (filtering large lists, charts) using `useTransition` or `useDeferredValue`, maintaining 60 FPS responsiveness.

4. How should you answer "Tell me about a time you had a technical disagreement with a teammate"?

Follow the STAR framework: Set the Situation (e.g. choosing between Redis caching vs Database Indexing for an endpoint with 10k RPM). Define the Task (we needed sub-50ms latency without ballooning infrastructure costs). Explain the Action (rather than arguing, I proposed building a quick benchmark with `locust`, collected empirical data, and discussed trade-offs openly). Highlight the Result (we adopted compound B-tree indexing which saved \$400/month in cache servers while maintaining 38ms p95 latency, and the team established a benchmark-first culture).
