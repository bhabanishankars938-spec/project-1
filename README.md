## HireNexa 2.0 — Where Talent Meets Opportunity

A unified, centralized recruitment and video conferencing platform featuring:
- **HireNexa Connect**: Real-time WebRTC audio/video meetings with in-call chat, screen sharing, and waiting room controls.
- **Recruitment Engine**: Candidate pipeline management, job boards, and structured interview scheduling.
- **Assessments**: Online examination system, coding environment, and live scorecards.
- **Role-Based Access Control**: Multi-tenant support for Candidates, Recruiters, Company Admins, and Platform Owners.

### Quick Start

1. Install dependencies:
   ```bash
   pip install -r HireNexa_Advanced/requirements.txt
   ```

2. Run migrations:
   ```bash
   python manage.py migrate
   ```

3. Start development server:
   ```bash
   python manage.py runserver
   ```
